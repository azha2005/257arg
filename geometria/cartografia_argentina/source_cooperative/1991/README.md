## Processing Notes

Census data from Argentina's 1991 National Population and Housing Census, aggregated at census tract (radio censal) level. Includes basic and extended questionnaire data with expansion factors.

Join columns: radios.parquet COD_1991 ↔ census-data.parquet id_geo

Data validation: Total population 32,615,528 (via PERSONA_EDAD). All 24 provinces present with clean UTF-8 province names.

## Known Issues

Santa Fe province has 581k records with NULL SEXO in source REDATAM data - this is a source data quality issue, not a processing error. EDAD is complete and yields correct population totals. NULL SEXO values are coded as 'Sin dato' in the output.
