## Processing Notes

Census data from Argentina's 2001 National Population and Housing Census, aggregated at census tract (radio censal) level. Extracted using Open Redatam, an open source tool for recovering REDATAM database contents.

Join columns: radios.parquet COD_2001 ↔ census-data.parquet id_geo
