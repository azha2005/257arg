# Cantón: diputados nacionales 1920

Transcripción de PDF 56–68, páginas impresas 49–61, tomo II. Diez distritos, 278 filas, 1.374 celdas: 939 números y 435 marcas. Sin celdas ilegibles pendientes, pero con categorías ausentes publicadas como marcas.

Abrir [TRANSCRIPCION_1920.md](TRANSCRIPCION_1920.md) para leer las tablas o usar [canton_1920.csv](canton_1920.csv). JSON canónico: `canton_1920.json`.

**Capital tiene una discordancia cronológica en la fuente impresa de votantes: cita prensa de 1924 bajo encabezado 1920.** Se conserva con nota, sin decidir que sea una errata. Río Segundo conserva votantes mayores que inscriptos, tal como se lee en la página.
