# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/azha2005/257arg/security/advisories/new)
rather than opening a public issue.

Relevant reports include, for example, a problem in the GitHub Actions
workflows that build and deploy the site, a leaked secret, a vulnerable
dependency in the Python tooling, or tampering with published data or maps.

Errors in election data that are not security issues can go in a regular issue.

I'll acknowledge reports as soon as I can and coordinate disclosure with you
once a fix is available.

---

# Política de seguridad

Para reportar un problema de seguridad, usá el
[reporte privado de vulnerabilidades](https://github.com/azha2005/257arg/security/advisories/new)
de GitHub en lugar de abrir un issue público. Los errores en los datos electorales
que no sean de seguridad pueden ir en un issue común.
