# Transferencias 2009 → 2015p

Estimaciones ecológicas, no observaciones de cambios individuales de voto.

[Abrir gráfico con selector provincial](sankey_2009_2015p.html) | [PNG](sankey_2009_2015p.png)

Base usada: 4203 circuitos, 5 grupos y 0 departamentos.
Cobertura del padrón de origen: **92,53 %** (25,542,285 de 27,605,572).
Penalización elegida por validación cruzada: 2e-06; separación: 42.4 puntos.

Filas no identificadas: Proyecto Sur, Blanco y nulo.
Filas cerca del promedio: PRO / Unión-PRO, Peronismo Federal.
Sensibilidad principal / Calvo: cambian 6,000,934 votos (21,08 % del total modelado).
El bootstrap no mide toda esta sensibilidad a la especificación.
