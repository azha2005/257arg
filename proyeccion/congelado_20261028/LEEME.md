# Código congelado el 28-oct-2026

`codigo_congelado.zip` conserva 82 archivos de código y documentación de `proyeccion/`, incluidos los motores operativos, simuladores, ICG e Israel. `MANIFEST.json` enumera tamaño y SHA256 de cada archivo copiado a `codigo/`. El ZIP no incluye las matrices grandes de datos ni las imágenes; sus fuentes y hashes se registran en los experimentos.

SHA256 del ZIP:

`1a9f0a432d6bdc1ee0fc4d7ee46ced1fec4dcd7d407495066d7873ea58364b07`

Esta versión ya conocía resultados de 2023/2025. Conservarla impide modificar retrospectivamente lo probado; no la transforma en una versión disponible en 2021. El experimento `../paso2021_ciego/` usa este código y separa la configuración congelada de una selección/calibración de constantes realizada exclusivamente con elecciones anteriores a PASO 2021.

Los archivos de `codigo/`, `MANIFEST.json` y el ZIP se conservan como snapshot. Cualquier corrección o modelo posterior debe guardarse fuera de este snapshot, junto con su propia validación.
